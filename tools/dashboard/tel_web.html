Remote control

    A command counts as done only when the car's own telemetry shows the result: the broker's acknowledgement means the broker has it, not the car. START needs a fresh arming each time and only works from READY_WAITING. RESET clears a safety latch only after the car has been still for 0.5 s.

    Missing and bad data

    An event starts when a sensor stops being VALID and ends when it is VALID again. STALE = its frames stopped (or, for the IR raws, the value froze); INVALID = a reading outside what the sensor can give; UNAVAILABLE = the frame carries no value for it (no producer); DISCONNECTED = the whole link is down. Sensors that never reported are listed on the Overview, not here.

    Guided capture

    1. Put the car on the track with both IR sensors over white, keep it still.
    2. Move it so both sensors sit over the black line body, keep it still.
    3. Read the verdicts. Then slide the car across the line and watch the live zones.
